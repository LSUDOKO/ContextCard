# ContextCard

The Context-Aware Financial Agent for Enterprise Data Teams.

Package manager: bun.

## Commands

- dev: `bun dev`
- test: `bun test`
- typecheck: `bun typecheck`

## Layout

- `examples/`
- `packages/`
- `scripts/`

## Rules

- Run `bun test` before you say a change is done.
- Never commit secrets or `.env` files.
